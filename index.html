Qadha

Shafi'i school

How qadha works

›
What it is
A fard prayer that isn't prayed before its time ends becomes a debt. You repay it, qadha, by praying it later with the same rakaat: Subuh 2, Zohor 4, Asar 4, Maghrib 3, Isyak 4.
When each time ends
Subuh at syuruk (sunrise). Zohor when Asar comes in. Asar at Maghrib (sunset). Maghrib when Isyak comes in. Isyak at Subuh the next morning, so it stays open past midnight. Al-Kafi #266
How soon
Missed because you slept or forgot: make it up when you remember, and doing it soon is sunat. Missed without an excuse: making it up straight away is wajib. Al-Kafi #1608
Which first
Oldest first: Subuh before Zohor, Zohor before Asar. Keeping that order is sunat, and prayers missed without an excuse go before ones missed with one. If the current prayer's time is safe, it's sunat to make up the missed one first; if it's running out, pray the current one first. Al-Kafi #1608
Any time of day
A missed fard prayer can be made up even after Asar, when sunat prayers are normally avoided. Irsyad al-Fatwa #164
Niat
Name the prayer you're making up, for example:Sahaja aku solat fardu Zohor empat rakaat qadha kerana Allah Taala.
Missed for years
Make them up as far as you're able, a few at a time if need be, until they're done, along with taubat. Count them by your best estimate; if you've lost count, keep going until you're sure none are left. Irsyad Hukum #5 Al-Kafi #2057
Not owed
Prayers missed during haid or nifas are not made up. Irsyad al-Fatwa #287

This follows the Shafi'i school as Malaysia's fatwa offices teach it. For your own situation, ask an ustaz or your state mufti.

    Your own Supabase

    About ten minutes, once. Supabase's free plan is plenty for one person. Do the steps on a computer or in Safari, then come back.

    1. Make a free project. Sign up at supabase.com and create a new project. Any name and region will do; Singapore is closest to Malaysia.
    2. Add Dayline's tables. In the project, open SQL Editor, paste this in and press Run. It makes a private table and a private file store that only your account can read.
      Show it
    3. Skip the confirmation email. Under Authentication, Sign In / Providers, open Email and turn off Confirm email. (Or leave it on, and confirm from the email Supabase sends.)
    4. Connect. Under Project Settings, API Keys, copy the publishable key (or the anon public one), and under Data API the Project URL. Paste both here.

    5. Make your account. Back in Settings, enter an email and a password and tap Create account. From then on everything syncs by itself.

    Reminders, once

    Your project sends the reminders, so it needs a small function, a few more tables and a key of its own. About ten minutes, on a computer.

    1. Make a key. Dayline makes a key pair for your project right here. Copy both halves for step 4.

      The private half is shown only now. Paste it into Supabase and nowhere else.

    2. Add the reminder tables. In SQL Editor, paste this in and press Run. It already has your project's address in it.
    3. Add the function. Under Edge Functions, choose Deploy a new function, then Via Editor. Name it remind, replace the code with this, and deploy. Then, in its settings, turn off Verify JWT (sometimes called Enforce JWT verification).
    4. Add the key. Under Edge Functions, Secrets, add VAPID_PUBLIC_KEY and VAPID_PRIVATE_KEY, each with its half from step 1.
    5. Turn them on. Close this, tap Turn on reminders, then Send a test.
